# About

Hi, I’m Taym Haddadi, a Rust and systems engineer.

My background spans browser engines, IoT and smart-home systems, backend infrastructure, and security. I have worked on Zigbee communication, device commissioning, eventing, APIs, observability, databases, proxies, and production systems.

I’m also a Servo maintainer and open source contributor. In Servo, I work on browser internals and web platform features such as workers, streams, IndexedDB, WebIDL bindings, and WPT testing.

This blog is where I write about Rust, Servo, browser internals, open source, IoT systems, infrastructure, security, and practical engineering stories from real debugging sessions.
